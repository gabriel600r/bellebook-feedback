# BelleBook - Feedback & Support

BelleBook is a professional appointment booking app for beauty salons, nail technicians, and aesthetics professionals.

## How to report issues or suggest features

1. Go to the [Issues](https://github.com/gabriel600r/bellebook-feedback/issues) tab
2. Click "New Issue"
3. Describe your issue or suggestion
